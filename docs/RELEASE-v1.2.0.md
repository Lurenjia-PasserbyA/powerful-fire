# Powerful Fire v1.2.0 — 粒子、后坐力与战斗反馈

发布日期：2026-11-20

v1.2.0 是一次表现层专项迭代，借鉴 NEON SURGE 的粒子池、爆炸环、枪口/命中火花、拖尾和方向性后坐力，在不改变模拟判定与数值平衡的前提下，把“打中了”和“开火了”做得更清楚。

## 新增表现层

| 模块 | 实现 |
| --- | --- |
| 粒子池 | `src/render/effects.ts`，420 粒子上限，Sprite 复用，加色混合 |
| 程序化纹理 | 柔光 `glow`、冲击波环 `ring`、横向拖尾 `streak`，无外部美术依赖 |
| 枪口 | 每次施法在枪口方向生成白色核心闪光 + 5 颗方向火星 + 枪身余辉 |
| 命中 | 白色/武器色火花；单次伤害 ≥55 追加冲击环、镜头轻震与 22ms hitstop |
| 击杀 | 按敌人类型取色爆炸；Boss 使用 190 半径冲击波、2.4 倍粒子与 70ms hitstop |
| 爆炸 | 投射物爆炸按 `fx:explosion` 生成径向光点 + 扩散环 + 白色闪光 |
| 拖尾 | 玩家高速移动、敌人余烬、飞行投射物；静止投射物不生成拖尾 |
| 粒子预算 | 玩家/敌人/弹道拖尾分别在 330/310/300 粒时停止，给命中与爆炸保留至少 120 粒 |
| 后坐力 | `camera.recoil` 按施法反方向偏移：普通 2.4、重击 5、霰弹 5、光束 7.5、大招 12；全自动 0.9 避免持续拉扯 |
| 准星 | `crosshair.kick` 每次施法短暂放大，普通 0.08、重击 0.16、大招 0.26、全自动 0.05 |
| 受击/死亡 | 玩家受击红色爆炸 + 原有红闪，死亡 130 半径红爆与强震屏 |

事件契约同步扩展：`skill:cast` 带 `aimX/aimY`，`enemy:hit`、`enemy:kill`、`player:hurt` 带坐标，新增 `fx:explosion`。表现层只消费事件，不读取或修改伤害判定。

## 验收

- `pnpm typecheck`、`pnpm build` 通过。
- `pnpm test:server` 4/4 通过。
- 1280×720 实机：单发/连射可见枪口闪光、弹道拖尾、命中火花、击杀爆炸、方向后坐与准星扩散。
- 780×360、DPR3 触屏视口：HUD、技能槽、准星与特效层正常渲染，无布局溢出。
- 压测 `120 敌人 + 400 投射物`：1280×720 下保持 60 FPS（16.6ms/帧）；静止投射物不产生拖尾堆积。
- 粒子层与投射物同时满载时，命中特效仍能获得预留粒子上限。

## 已知限制

- 全屏“上一帧淡出”残影未实现；Pixi 下需额外 RenderTexture 后处理，当前以局部 Sprite 拖尾替代。
- 粒子为加色 Sprite，极端同屏下仍受 420 上限约束；超限时优先保留命中/爆炸，丢弃新拖尾。
