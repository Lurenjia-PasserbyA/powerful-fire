# Powerful Fire v1.2.2 — 武器手感强化

发布日期：2026-11-21

v1.2.2 是一次轻量手感调校：不改变技能伤害、冷却和数值平衡，只提高开火与命中的反馈强度。

## 调整

- **方向后坐力**：普通 2.4 → 3.2，重击 5 → 6.5，霰弹 5 → 6.5，光束 7.5 → 9，大招 12 → 16；全自动 0.9 → 1.3，避免持续拉扯。
- **镜头冲击**：普通武器每次开火新增 1.5 轻震；光束 3.2、霰弹 2.6；重击 2.4、大招 8。
- **准星扩散**：普通 0.08 → 0.12，重击 0.16 → 0.2，大招 0.26 → 0.32，全自动 0.05 → 0.07。
- **枪口闪光**：火星 5 → 6，方向速度与尺寸提高；白色核心 24 → 28，枪身余辉 30 → 34。
- **命中反馈**：火花 5/3 → 6/4；高伤冲击环阈值 55 → 50；重击 hitstop 22 → 32ms。
- **击杀反馈**：小怪爆炸半径 58 → 66，镜头震动 2.2 → 3.2；Boss 半径 190 → 210，hitstop 70 → 90ms。
- **粒子预算**：420 → 480；拖尾让位阈值提高到 380/360/340，给命中与爆炸保留更多空间。

## 验证

- `pnpm typecheck`、`pnpm build` 通过。
- 方向后坐实测：普通 3.2、光束 9、霰弹 6.5、大招 16。
- `120 敌人 + 400 投射物` 压测：1920×1080 保持 59–60 FPS（16.7ms/帧）。
