# Powerful Fire v1.0.1 — 移动端触控与适配修复

发布日期：2026-11-13
基线：v1.0.0（`85e62ab`）

## 用户反馈

Android 实机（2340×1080）截图暴露：左右大量黑边、部分面板过小、右半屏只能“点哪打哪”、大招按钮完全无反应、HP/体力/槽位与触屏控件重叠、商店和自动开火遮挡小地图与闪避按钮。

## 修复内容

### 1. 右半屏第二摇杆

- 右半屏改为浮动瞄准摇杆：按下位置出现摇杆底座与旋钮，拖动方向换算为世界准星（相对玩家固定 900 单位距离），松手立即停火。
- 死区 8px，摇杆最大位移 62px；固定虚线底座标注“瞄准”，提示右侧可操作区域。
- 右区占屏宽 54%，与左摇杆 46% 无重叠。

### 2. 全屏适配与面板放大

- `Viewport` 以 1280×720 为设计基准，按窗口宽高比扩展逻辑画布（宽屏加宽、窄屏加高），缩放取 `cssHeight/logicalHeight`，偏移固定 0，消除 letterbox。
- HUD 不再跟随世界视口缩放，独立使用 `clamp(0.95, viewport.scale, 1.18)`；780×360 手机上 HUD 从 0.5 倍提升到 0.95 倍。
- `viewport-fit=cover`，`html/body/#app/#stage` 强制 100% 尺寸；触屏按钮、槽位、字体用 `clamp(px, vmin, px)` 自适应。

### 3. 大招不可释放

- 根因：`startLoadout.ultimate` 默认 `null`，旧存档 `loadout.ultimate` 也为 `null`，`tryUltimate` 首行直接返回。
- 默认装配改为 `ult_firesky`，并加入初始解锁列表；存档迁移优先沿用已解锁 `ult_*`，否则补默认大招。
- 触屏按钮显示“大招 N%”；未装备时点击直接打开商店；充能不足时提示当前百分比；释放后正确扣除体力并进入 6s 持续火雨。

### 4. 触屏 HUD 重排

- 触屏模式隐藏重复的 `.hud-vitals` 与 `.hud-slots`，新增紧凑触屏 HP 条（`100 / 100`、低血深红），体力条在其下。
- 商店与自动开火移到左侧 XP 面板下方，右侧完整留给瞄准摇杆、闪避、大招。
- 槽位按钮保留底部居中，避免与右摇杆/大招重叠。

## 验收

环境：Node v22.23.2、pnpm 11.7.0；浏览器 CDP 模拟 780×360、DPR 3。

- `pnpm typecheck`、`pnpm build`、`pnpm test:server` 全部通过。
- `#stage` / `#hud` 均为 780×360，无黑边。
- 右摇杆从底座中心拖 (+60, −20)：`aim≈{x:1104,y:35}`（玩家 250,320），`fireHeld=true`；松手 `aim=null`、`fireHeld=false`。
- `debug.giveUltimate()` 后按钮显示“大招 100%”；按下后 `charge=0`、`ultTimer=6`、体力 100→82。
- HP 条文本随伤害更新（测试 40 血时显示 `42 / 100`，基地内回复中）；`.hud-vitals` 计算样式为 `none`。
- 商店按钮/自动开火 rect 为 `x16,y96,w43,h30` 与 `x16,y136,w78,h30`；商店打开后 780×360 全屏、24 张卡片、网格可滚动（scrollHeight 1449）。
- 桌面 1920×993 HUD 正常，无 letterbox。

## 已知限制

- macOS 包未签名/未公证，首次运行需按 `desktop/README.txt` 移除隔离属性。
- Android 为 debug APK，未做 release 签名；上架商店需另配 keystore。
- 触屏冲刺仍为键盘专属；自动开火辅助瞄准为 20° 锥形，超远距离可能需手动修正。
- 商店在小屏为全屏浮层，需纵向滚动查看全部 24 张卡片。
