# Powerful Fire v1.2.3 — 联机逻辑修正

发布日期：2026-11-27

v1.2.3 集中修复局域网/服务器联机：主机仍是唯一模拟端，但客机不再只是“看快照 + 发输入”，装备、购买、升级、伤害归属和重连都改为真正走主机权威链路。

## 联机修复

- **世界种子同步**：欢迎包下发主机 `world.seed`，客机重建地面装饰；双方地图观感一致。
- **装备权威化**：客机切槽/换大招会即时提交给主机；主机校验 `registry` 和 `unlocked` 后写回远端玩家。客机本地待确认状态保留 1.5s，避免被 20Hz 快照立刻回滚。
- **购买/升级走主机**：新增 `buy` / `upgrade` 协议与 `economy.ts`；客机购买扣远端玩家 XP、解锁写入主机共享进度，再通过快照同步回来。
- **队伍共享升级**：体质/疾行/烈焰升级按队伍应用，谁付款都提升当前所有玩家；新队友加入时自动套用已购升级。
- **伤害与击杀归属**：投射物、区域、点燃持续伤害、分裂/链式投射物都携带 `ownerId`；击杀、终极充能归实际伤害来源。敌人自爆等无主击杀回退到“最后伤害来源”，不再默认记到房主。
- **快照补齐世界状态**：波次、群系、时长、种子、共享进度、Boss HUD 与玩家击杀/死亡/护盾全部同步；客机 HUD 使用主机元数据。
- **连接生命周期**：加入/心跳/快照缺失自动重新 join；房主重启时服务端主动关闭旧客机；本地房主退出发送 `host-left`；幽灵客机 5s 无心跳自动清理；重连旧回调用代际号隔离。

## 验证

- `npx tsc --noEmit` 通过。
- `npm run build` 通过。
- `npm run test:server`：6/6 通过。
- 专用服务器 `FINAL` 房：客机 2P · 6ms；客机移动后主机远端 x 从 240 → 297。
- 客机购买 `proj_chain`：主机远端 XP 600 → 300，`spent` 520，`unlocked` 同步到客机。
- 队伍升级 `hp`：主机与客机最大生命同时 112 → 124，等级 2。
- 客机切槽 `proj_chain`：主机远端槽位同步为 `["proj_fireball","proj_chain",null]`。
- 伤害归属：直接以客机 `ownerId=2` 击杀，客机击杀 +1、房主 0；无主 `killEnemy` 也回退到客机。
- 房主重启：客机自动重连，恢复到 2P，快照继续推进。
- 单文件版 817,278 B，`file://` 启动菜单正常显示 v1.2.3。
