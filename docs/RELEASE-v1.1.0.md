# Powerful Fire v1.1.0 — 内容扩量与联机入口

发布日期：2026-11-20

v1.1.0 是 v1.0.1 的内容与体验扩量版本：新增 14 个技能、9 种敌人、2 个群系与 8 个地标，加入开始/暂停菜单、局域网联机入口、扁平科技风 UI，以及镜头冲击/命中停顿/移动加速等手感改进。

## 内容

### 技能（24 → 38）

| 系别 | 新增 |
| --- | --- |
| 法棍 | 赤焰长签、焦香面包雷、蒜香面包盾 |
| 热武器 | 烬火霰弹、燃素地雷、熔切射线 |
| 火球 | 炽焰长矛、彗星弹、萤火群 |
| 法术 | 阳炎射线、炽环、灰烬虹吸 |
| 大招 | 流星风暴、超新星 |

新增行为：`shotgun`（6 发扇形霰弹）、`spear`（4–5 目标贯穿）、`beam`（430–540 直线瞬发伤害/治疗）、`ult_supernova`（半径 520 爆发 + 60 护盾）。

### 敌人（7 → 16）

| 类型 | 角色 | 行为 |

| 烬猎犬 `cinderhound` | charger | 蓄力后高速冲锋 |

| 黑曜卫士 `obsidian_knight` | melee | 重甲近战，缓慢逼近 |
| 熔岩浮灵 `magma_wisp` | caster | 远程灼烧弹幕 |

### 地图（5000×5000 → 9000×7000）

五个群系与危害：

- 灰烬荒原（默认，无环境危害）
- 焦木林（雾区减速 38%）
- 蓝晶回廊（晶尘 7 DPS + 减速 14%）
- 熔岩裂谷（岩浆 9 DPS）
- 大火山口（熔流 12 DPS）

八个地标：坠星坑、旧哨塔、焚林祭坛、晶簇塔、灰烬祭坛、熔流桥、热流喷口、火山口边缘；小地图新增群系色块与地标菱形点。

### 开始菜单与联机

- 进入游戏前显示：继续/新档、联机合作、操作说明；存档等级、击杀、行动时长；38 技能/16 敌人/5 群系/63km² 情报；服务端在线状态。
- 联机抽屉：呼号、房间码、本机同浏览器 / 局域网服务器 / 直连 WS 三种模式；`/api/network` 自动探测本机局域网 IPv4 并预填地址。
- `net=host|join` 或 `autostart=1` 跳过菜单；新档清存档后以随机 seed 重载。
- 联机中 Esc 不再打开暂停菜单，避免冻结房主模拟。

### UI / 手感

- 扁平科技风：深蓝黑底、青色数据边、直角切角、扫描线、等宽标签、四角括号。
- 触屏短屏横屏：闪避/大招右下横排，避免压住小地图；瞄准摇杆缩小到 132px 并上移；商店单行筛选 + 四列密集卡片。
- 受击、威力技能、大招、Boss 转阶段触发镜头冲击；受击与 Boss 转阶段 55–110ms 命中停顿；移动起步/转向 24/s 指数加速。

## 已知限制

- 桌面包未做代码签名/Apple 公证，首次运行需按 `desktop/README.txt` 处理隔离属性。
- Android 为 debug APK，未上架商店；正式分发需配置 release keystore。
- 联机为房主权威，依赖房主浏览器持续在线；公网跨 NAT 仍需端口转发或中继，未内置 STUN/TURN。
- 存档保存在浏览器 IndexedDB，同设备不同浏览器不共享。
